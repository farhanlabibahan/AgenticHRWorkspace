# Code of conduct

Source follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be welcoming, be kind, and focus on what's best for the
people who use and build Source. Harassment in any form isn't tolerated.

To report a problem privately, message a maintainer on GitHub. If it
involves a maintainer, say so, and it will be handled by someone else.
Reports are kept confidential.
