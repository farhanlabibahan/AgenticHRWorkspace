export const px = { imageRendering: 'pixelated' };

export function Asset({ file, height, small, wide = false, dark = false, note }) {
  // Whole multiples only: a box narrower than the image squeezes it and the
  // cells come out uneven. `small` is the height under 640px; `wide` spans
  // both columns.
  return (
    <figure className={`flex flex-col gap-2 ${wide ? 'md:col-span-2' : ''}`}>
      <div className={`flex flex-1 items-center justify-center rounded-card p-6 ${dark ? 'bg-[#0f0f0e]' : 'bg-surface'}`}>
        <img
          src={`./brand/${file}`}
          alt=""
          className="h-(--h-sm) sm:h-(--h)"
          style={{ '--h': `${height}px`, '--h-sm': `${small ?? height}px`, ...px }}
        />
      </div>
      <figcaption className="font-mono text-xs text-ink-2">
        <a href={`./brand/${file}`} download className="hover:text-ink">
          {file}
        </a>
        {note ? <span> · {note}</span> : null}
      </figcaption>
    </figure>
  );
}

export function Icon({ file, size, zoom = 1, label }) {
  return (
    <figure className="flex flex-col items-start gap-2 self-end">
      <img src={`./brand/favicon/${file}`} alt="" width={size * zoom} height={size * zoom} style={px} />
      <figcaption className="font-mono text-xs text-ink-2">
        <a href={`./brand/favicon/${file}`} download className="hover:text-ink">
          {label ?? file}
        </a>
      </figcaption>
    </figure>
  );
}

# Brand

The logo is the orb and the word **Source**. The orb is the app's own ember orb, the one on the homepage (`<Orb palette="ember" />`): a lit dome dithered to two tones, ink `#3A1A12` and paper `#F2A58F`, through an 8×8 Bayer matrix. The word is Geist Medium, converted to outlines, so no file needs a font installed.

Every file lives in `public/brand/` and is served from `/brand/…`. Click a file name to download it. `public/brand/README.md` has the full file list and how to regenerate it all from `scripts/brand/`.

## Lockup

Use `-light` (ink text) on the canvas or white, and `-dark` on the dark canvas or anything darker than mid-grey. Each comes as SVG and as PNG at 1×, 2× and 4×.

## Favicons

`SRC` in Fragment Mono across the orb, with the dither cleared around each letter. It's only for icons; everywhere else, the sidebar included, the logo is the lockup. Each size is drawn on its own grid, one pixel per cell, never shrunk from a bigger image.

In the app, `src/app/favicon.ico` is the only `rel="icon"`, on purpose. Given an SVG or a 32px PNG as well, Chrome prefers it and scales it down for 1× tabs, which averages the dither to mush. With the ICO alone, Chrome shows the 16px and 32px frames pixel for pixel.

## Using it

- **Clear space.** Keep half the orb's diameter clear around the lockup and the mark. For the wordmark alone, keep the height of its capital S clear.
- **Minimum size.** The lockup and the mark at 32px, the wordmark at 16px tall. Anything smaller gets the favicon.
- **Whole pixels.** The orb is a grid of square cells: use 32, 64, 96 or 128px for the standard files and 64, 128, 192 or 256px for `-large`, or the cells come out uneven.
- **Don't** recolor the orb, smooth or blur the dither, set "Source" in another weight or font, or rearrange the mark and the word.
