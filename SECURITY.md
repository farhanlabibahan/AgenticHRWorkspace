# Security

Source holds candidates' personal data, so we take reports seriously and
respond quickly.

## Reporting a vulnerability

**Please don't open a public issue.** Report it privately through GitHub:
**Security → Report a vulnerability** on this repository. Include what you
found, how to reproduce it, and what an attacker could do with it.

We'll acknowledge your report within three business days and keep you
updated as we fix it. Please give us a reasonable time to ship a fix before
you disclose anything publicly; we're happy to credit you when we do.

This covers this repository and the hosted Source ATS. Please don't test
against other people's workspaces or data, and don't degrade the service
for anyone else.

## Supported versions

Fixes land on `main`. Self-hosted installs should update to the latest
release to get them; see [the README](README.md) for how to update.
